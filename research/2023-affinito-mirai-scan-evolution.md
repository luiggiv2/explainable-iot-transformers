- **Dataset(s)**: Long-running darknet/network-telescope capture of TCP SYN scanning traffic, 2016–2022 (six years), filtered for packets bearing the Mirai packet-level signature.
- **Models / Methods**: Signature-based traffic filtering plus longitudinal/temporal measurement analysis (not an ML classifier).
- **Key metrics reported**: Identifies and tracks scanning packets that carry the original Mirai source-code fingerprint — the **TCP initial sequence number field set equal to the numeric value of the destination IP address**, instead of a random 32-bit value — across darknet traffic from 2016 through 2022, showing this signature is still actively used by scanners six years after the source code leaked.
