# Attribution-Driven Explainable Intrusion Detection with Encoder-Based Large Language Models
- **Authors**: Umesh Biswas, Shafqat Hasan, Syed Mohammed Farhan, Nisha Pillai, Charan Gudla
- **Year / Venue**: 2026 (arXiv preprint, submitted April 2026) — `preprint`, cs.CR. Preprint-only as of 2026-07-14 (checked arXiv journal-ref/comments field — none present — DBLP, which lists only the CoRR/arXiv entry, and a general web search that surfaced no journal/conference publication).
- **DOI**: 10.48550/arXiv.2604.06266 (arXiv preprint DOI)
- **URL**: https://arxiv.org/abs/2604.06266
- **Cluster**: 1, 3 (surfaced independently by both cluster searches; duplicate fact sheets merged into this one)
- **Dataset(s)**: CICIDS2017 (used in an SDN intrusion-detection context; after deduplication: 366,870 samples — BENIGN 243,212; DDoS 121,606; Web Attack (Brute Force + XSS + SQL Injection merged) 2,053). NOT CICIoT2023, NOT IoT-specific — it is SDN/enterprise network traffic.
- **Models / Methods**: Fine-tunes two encoder-only transformers — RoBERTa (12-layer) and DeBERTa (disentangled attention) — on flow-level features serialized into text via a deterministic template: s(x) = "Feature₁ is x₁" ⊕ "Feature₂ is x₂" ⊕ ... (ordered concatenation preserving one-to-one feature-to-token mapping for downstream attribution). Applies Integrated Gradients (via the Captum library) to the fine-tuned encoders for coarse 3-way classification (BENIGN / DDoS / Web Attack).
- **Key metrics reported**: DeBERTa (merged classes): Macro-F1 0.9902, Weighted F1 0.9993, Web Attack F1 0.9717 (Prec 0.9826 / Rec 0.9611); RoBERTa (merged classes): Macro-F1 0.9704, Weighted F1 0.9986, Web Attack F1 0.9130 (Prec 0.9065 / Rec 0.9197); both near-perfect on BENIGN/DDoS (DeBERTa: Benign F1 0.9995, DDoS F1 0.9994; RoBERTa: Benign F1 0.9989, DDoS F1 0.9994).
- **XAI method (if any)**: **Integrated Gradients via Captum** (the same primary method specified in our own protocol) — attributions computed per-token/per-feature along a baseline-to-input path, used to verify per-class reliance on specific flow features (e.g., RoBERTa relies heavily on Destination Port for BENIGN and Flow IAT Min for Web Attack, suggesting a possible "dataset-specific shortcut"; DeBERTa shows more distributed, less single-feature-dominant attributions).
- **Relevance to our RQs**: **The single closest direct competitor found in this cluster.** It replicates almost exactly our intended pipeline — deterministic "Feature is value" textual serialization of network flow records, fine-tuning of encoder-only transformers, and Captum Integrated Gradients for per-class, per-feature attribution (directly maps onto our RQ2/RQ3) — but on CICIDS2017/SDN traffic rather than CICIoT2023/IoT, using RoBERTa/DeBERTa rather than DistilBERT/TinyBERT, without SHAP cross-validation, and without any robustness-under-perturbation analysis (RQ4 is entirely open). Also does not include classical ML baselines (RQ1) or a footprint/latency analysis (RQ5). This paper should be discussed explicitly in our related work and used to justify novelty (IoT-specific dataset + smaller/edge-oriented encoders + dual XAI method + explanation robustness).
- **Stated limitations** (author-acknowledged): Evaluation limited to coarse 3-way classification (no fine-grained attack-subclass attribution); only single-head architectures tested; only two encoder models (RoBERTa, DeBERTa) analyzed; RoBERTa's heavy reliance on Destination Port is flagged by the authors themselves as a possible "dataset-specific shortcut" rather than genuine behavioral learning, and they explicitly call for testing whether findings generalize beyond CICIDS2017.
- **Quotable finding (paraphrased)**: Applying Integrated Gradients to encoder LLMs fine-tuned on deterministically serialized flow-feature sentences shows that different encoder architectures can reach near-identical classification accuracy while relying on measurably different features per attack class (e.g., one model leaning on a single port field, another spreading attribution across several timing statistics) — meaning high accuracy alone does not guarantee that a model has learned robust, generalizable attack signal rather than a dataset-specific shortcut.
